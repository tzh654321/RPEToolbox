3.旋转事件与距离生成普通事件
此界面依然有切割密度输入框。此模式下输入的x与y事件不再表示锚点在屏幕上的绝对位置，而是以(x^2+y^2)^0.5来表示与圆心距离，将距离和角度事件用极坐标的方式结合(0度表示上方，即y+)，再转换为x和y绝对位置。计算方法：每个事件未定义的时间段沿用上个事件的结束值，若没有上一个事件则使用下一个事件的起始值，先将x、y、旋转事件按规定切割密度切割成线性事件（"easingType" : 1），计算出一系列距离事件，再计算出一系列绝对的的x、y事件，最后和原旋转事件汇总并输出

加入功能：事件类型转换

interface EventLayerDataRPE {
    moveXEvents: EventDataRPE[];
    moveYEvents: EventDataRPE[];
    rotateEvents: EventDataRPE[];
    alphaEvents: EventDataRPE[];

extended: {

在该模式下会出现七个选择框，指转换来源，分别为：X轴位移、Y轴位移、旋转、透明度、速度、X轴缩放、Y轴缩放
每个选择框选项中也有X轴位移、Y轴位移、旋转、透明度、速度、X轴缩放、Y轴缩放，指转换目标
默认选项和转换来源保持一致
意思是：将事件来源的type转换为目标type
即"type" : (number)

加入功能：图片转音符画
用户有以下几个选项/输入框：
   图片文件路径（可以拖动导入，至少要对jpg、png格式支持）
   音符类型（选择 tap/drag/flick/hold）
   音符间隔（填几分音符，可以和前文切割密度使用一个变量）
   颜色处理方式（选择 染色、矫正颜色染色、不透明度替代亮度）
   是否使用原图片大小（默认否）
      若否，出现以下输入框：
      x像素数（默认65）
      y像素数（默认65）
   是否自动调整音符宽度（默认是）
      若否，出现以下输入框：
      音符宽度（默认175）
音符有染色、透明度两个属性，默认值为"alpha" : 255,"color" : [ 255, 255, 255 ]，将输入图片按输入参数压缩后，以一个像素对应一个note的方式生成画面，注意对png格式透明度的支持，透明度为0的note可以去除，注意hold持续时长应与音符间隔一致。
若不调整音符宽度，最左侧note的x坐标为-587.5，最右侧note的x坐标为587.5，其余音符平分中间的x坐标
若调整音符宽度，计算(675*2/x像素数/175)以得到所有音符的宽度，再进行对x坐标的平分，保证所有音符都完整地处于±675内。
若选择 染色 模式，直接将像素颜色填入"color"后的数组
若选择 矫正颜色染色 模式，应根据tap/drag/flick/hold的主要颜色 #0AC3FF #F0ED69 #FE4365 #9AE8FD ，使填入json的色号和note颜色在经过正片叠底算法处理后与原图颜色色相一致，原图的 #FFFFFF 应处理为无饱和度的最亮灰色。
若选择 不透明度替代亮度 模式，应保持note的"color" : [ 255, 255, 255 ]，将原图像素亮度与不透明度的乘积填入"alpha"

## 新功能：纵连音高
所在功能组：片段处理。该界面有 bpm/填充音符（tap/drag/flick/hold/与输入一致（默认，每个键后填充的音符种类 分别与其对应的键 一致））/输入json，在输入了一系列音符后显示一个可视化界面用于显示音符，音符颜色前文提过，音符宽度175，x显示范围±675，时间范围由输入的音符决定，能纵向滚动与缩放，hold显示为空心框，每个音符边显示音高（如C4,A#0，Gb7）或0（默认，表示单键）与note数量，点击音高手动输入，对于非hold，数量也手填，对于hold，数量由bpm、音高推算，无法手动填。右键hold将其切换为滑音，其后端也出现音高输入框，可以制作音高线性变化的滑音效果。提供预览功能，声音由锯齿波模拟
